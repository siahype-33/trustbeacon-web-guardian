# Trustbeacon Web Guardian

Build a web application called 'NetVeritas' for checking website safety and certificate trust. Use a crisp, high-contrast minimalist slate-and-emerald color theme (dark charcoal background #0f172a, crisp white text, emerald green #10b981 for safe, amber #f59e0b for warnings, crimson #ef4444 for danger—avoid any purple gradients or futuristic sci-fi clichés). Put a clean URL input bar at the top with an 'Inspect Domain' button. When a URL is submitted, show a 'Trust Rating' out of 100 and four clean analytical panels: URL & Phishing Signals, TLS Certificate & Issuer Check, HTTP Security Headers, and Community Threat Log
